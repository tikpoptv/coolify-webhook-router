2. เชื่อมต่อ Coolify API

ใช้หาว่า backup, scheduled task และ image scan เป็นของโปรเจคไหน (event deploy มีชื่อโปรเจคมาอยู่แล้ว) — สร้าง token ที่ Coolify → Keys & Tokens → API tokens สิทธิ์ read ก็พอ

3. ช่องสำรอง

ถ้า event ไม่ตรงกับกฎไหนเลย (เช่น event ของ server หรือข้อความทดสอบจาก Coolify) จะส่งมาที่นี่
